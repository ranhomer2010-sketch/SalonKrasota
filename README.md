# Салон Красота

Многостраничный прототип сайта салона красоты.

Страницы:

- главная;
- услуги и цены;
- салон и мастера;
- контакты и запись.

Визуальная система: Bebas Neue, розовый `#FF84BA`, жёлтый `#FFDF82`, голубой `#99C2FF`, кремовый `#FFEFE3`.

Вместо AI-фотогенерации используются фирменные растровые арты. Исходные изображения переведены в полиграфический screenprint с ограниченной палитрой и растром. Ту же обработку можно применить к реальным материалам салона.

Публичная версия после обновления GitHub Pages: https://ranhomer2010-sketch.github.io/SalonKrasota/

Сайт статический. Внешняя система записи открывается только после осознанного перехода пользователя.
