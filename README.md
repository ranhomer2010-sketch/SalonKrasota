# Салон Красота

Светлый анимированный прототип сайта салона красоты с услугами и ценами на главной странице и записью через YCLIENTS.

Публичная версия: https://krasota-salon-prototype.pastel-seal-2668.chatgpt.site

Сайт статический. Для публикации через GitHub Pages выберите ветку `main` и папку `/ (root)`.
